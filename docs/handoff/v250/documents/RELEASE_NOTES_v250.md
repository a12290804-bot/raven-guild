神秘散件在世界王商店以每件240樂子點取得，不混入普通怪物掉落，不計入原三套神秘裝備件數。自由混搭，原套裝與舊裝備保留。

怪物會隨難度增加生命、攻擊、防禦、速度與部分命中；首領多了蓄壓預告，下一次行動會削去部分護盾再重擊。控制可爭取空檔，噤聲／褪名可干擾這次蓄壓；封印仍依原規則壓制強化，沒有被改成通用暈眩。世界王原有架勢、階段與最難定位保留。

污染和探索濁度仍分開。污染跟隨本場選定重生難度；敵人在重生1／3／5取得更多污染招式。角色主動開啟代表技能的污染式後：初染保留原變化與代價；共鳴追加主要效果、支援型護住較虛弱的同伴；深染再擴及次要目標或全隊調養，自身負面代價也延長。村民有不同階段反應。

四套時裝、技能攻擊與首領大招使用已提供的圖片。時裝價格仍為500九玄幣或100渡鴉幣，只改外觀與感想；技能和污染數值不隨時裝改變。
